# AVERY-Documentation
Avery is a humanoid animatronic designed to sing and gesture to an audience. It has digital eyes that look around at random and a mechanical jaw that swings in time with music lyrics. 

This project began in the summer of 2021 when I was about sixteen years old. Avery was not intended to be my senior engineering project, but I adopted him as such after his prototype was built.

Avery takes inspiration from 1979-era Chuck E. Cheese cyberamic animatronics, the Rock-A-Fire Explosion, and Steve Koci's book "The Ultimate Guide To Do It Yourself Animatronics". 

This page is just an old project breakdown and includes more detailed documentation on the technologies I used to make this project. Thank you!
